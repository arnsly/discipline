# Таймер проектов

Мини-виджет для рабочего стола Windows + страница со сводкой. Ставить ничего не нужно — всё на встроенном PowerShell.

## Как открыть таймер

Двойной клик по **`Таймер.vbs`** в этой папке.

Удобнее закрепить:

- **Ярлык на рабочем столе** — правая кнопка по `Таймер.vbs` → «Отправить» → «Рабочий стол (создать ярлык)».
- **Автозапуск вместе с Windows** — Win+R → `shell:startup` → положить туда этот ярлык.
- **В панель задач** — у `.vbs` закрепления нет, поэтому сделай ярлык, в его
  свойствах в поле «Объект» впиши в начало `wscript.exe ` (с пробелом), и такой
  ярлык уже закрепляется.

Запущенных копий всегда одна: повторный двойной клик ничего не сломает.

## Горячие клавиши

Работают из любого окна, даже когда виджет спрятан:

| Клавиши | Что делает |
|---|---|
| **Ctrl+Alt+S** | старт / стоп по текущему проекту |
| **Ctrl+Alt+T** | показать / спрятать виджет |

Спрятанный виджет продолжает считать время — он просто не мозолит глаза.

## Углы экрана

Виджет прилипает к углам: перетащи его мышкой и отпусти рядом с углом — он
встанет ровно, с отступом 20 px. Угол запоминается, при следующем запуске
виджет появится там же.

Явно выбрать — правая кнопка мыши → «Прикрепить к углу» → любой из четырёх,
или «Свободно», если хочется поставить где угодно.

## Виджет

- **Старт / Стоп** — засечь время по выбранному проекту
- **выпадающий список** — выбрать проект (пока таймер идёт, список заблокирован)
- **+** — добавить новый проект
- **Сводка** — открыть `index.html`
- **×** — закрыть (идущий таймер при этом корректно остановится и запишется)
- **правая кнопка мыши** — заметка, углы, убрать проект, открыть папку

### Заметки

После каждого **Стоп** виджет спрашивает «что делала?» — одна строка, Enter
сохраняет, Esc или «Пропустить» закрывает без заметки. Заметки видны в разделе
«Записи» на странице со сводкой.

Забыла или хочешь исправить — правая кнопка → «Заметка к последней сессии…».

### Мелочи

Сессии короче 5 секунд не записываются. Раз в минуту идущая сессия сохраняется
на диск, так что при внезапной перезагрузке время не теряется — при следующем
запуске таймер продолжит идти. Если с момента старта прошло больше 12 часов,
«забытая» сессия отбрасывается.

## Файлы

| Файл | Что это |
|---|---|
| `Таймер.vbs` | запуск виджета |
| `widget.ps1` | сам виджет |
| `index.html` | страница со сводкой — работает и локально, и как сайт |
| `data.json` | все записи; это и есть твои данные |
| `data.js` | та же копия для локального открытия `index.html` |
| `sync.cmd` | отправка данных на GitHub (вызывается виджетом сама) |

## Сводка

Двойной клик по `index.html` или кнопка **Сводка** в виджете. Локально страница
читает `data.js`, поэтому после Стопа её надо обновить (F5).

На странице: крупные числа (сегодня, неделя с честным сравнением к прошлой,
среднее за день, всего), календарь с интенсивностью по дням, столбцы за три
недели и за двенадцать недель, разбивка по проектам и список записей с
заметками. Клик по дню в календаре показывает только его записи, клик ещё раз —
снимает фильтр. Светлая и тёмная тема берутся из настройки системы.

## Сводка в интернете

Папка подключена к GitHub: после каждого **Стоп** виджет тихо делает коммит и
пуш `data.json`, а GitHub Pages отдаёт страницу по адресу
**https://arnsly.github.io/discipline/**. Там она берёт свежие данные по сети и
обновляется раз в минуту, так что с телефона всё видно без единого действия.

Если пуш не прошёл (нет интернета) — ничего страшного: данные лежат локально и
уедут при следующем Стопе. Отправить вручную — двойной клик по `sync.cmd`.
