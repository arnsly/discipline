# Таймер проектов

Мини-виджет для рабочего стола Windows + страница со сводкой. Ничего ставить не нужно — всё работает на встроенном PowerShell.

## Файлы

| Файл | Что это |
|---|---|
| `Таймер.vbs` | запуск виджета (двойной клик) |
| `widget.ps1` | сам виджет |
| `summary.html` | страница со сводкой (двойной клик) |
| `data.json` | все записи — это и есть твои данные |
| `data.js` | та же копия, из неё читает `summary.html` |

## Виджет

Маленькое окошко поверх всех окон, в правом нижнем углу.

- **Старт / Стоп** — засечь время по выбранному проекту
- **выпадающий список** — выбрать проект (пока таймер идёт, список заблокирован)
- **+** — добавить новый проект
- **Сводка** — открыть `summary.html`
- **×** — закрыть (если таймер шёл, он корректно остановится и запишется)
- **правая кнопка мыши** — убрать проект из списка, открыть папку с данными
- виджет **перетаскивается** мышкой за тёмный фон или за цифры; позиция запоминается

Мелочи: сессии короче 5 секунд не записываются; раз в минуту идущая сессия
сохраняется на диск, так что при внезапной перезагрузке время не теряется —
при следующем запуске таймер продолжит идти (но если прошло больше 12 часов,
«забытая» сессия отбрасывается).

## Автозапуск вместе с Windows

Win+R → `shell:startup` → положить туда ярлык на `Таймер.vbs`.

## Сводка

Двойной клик по `summary.html` (или кнопка **Сводка** в виджете). Страница
читает `data.js`, поэтому после Стопа её нужно просто обновить (F5).

Что на ней: сегодня / неделя / месяц / всего, столбцы по дням за три недели,
разбивка по проектам, серия дней подряд и таблица последних сессий.
Светлая и тёмная тема — по настройке системы.
